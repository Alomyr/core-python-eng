# 🐍 Core Python Engineering Lab

Este repositório contém meus estudos aprofundados sobre a linguagem Python, focando em **Engenharia de Software** e preparação para a carreira de **Machine Learning Engineer**. Os estudos são baseados no curso de Python 3 do Luiz Otávio Miranda e em práticas de código limpo.

## 🎯 Objetivos
* Dominar a **Programação Orientada a Objetos (POO)** aplicada.
* Aplicar conceitos de **Clean Code** e tipagem (Type Hinting).
* Criar uma base sólida para o desenvolvimento de APIs e pipelines de IA.

## 🛠️ Tecnologias e Ferramentas
* **Python 3.12+**
* **Venv / Poetry** (Gerenciamento de ambientes)
* **Pytest** (Testes unitários)
* **Pylint / Black** (Linting e formatação)

## 📁 Estrutura do Repositório
A organização segue os módulos principais do curso:
- `01-logica-basica/`: Exercícios de sintaxe e lógica fundamental.
- `02-poo/`: Classes, herança, mixins e padrões de projeto.
- `03-modulos/`: Manipulação de arquivos, JSON, e bibliotecas padrão.
- `04-projetos-praticos/`: Implementações completas e integrações.
